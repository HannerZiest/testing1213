How to install the result in Krita
  1. Unzip the download. Each brush gets a folder with a .kpp preset and a _tip.png (and _grain.png if the brush had one).
  2. In Krita: Settings → Manage Resources → Open Resource Folder.
  3. Copy the _tip.png file into the brushes folder, and the .kpp into paintoppresets. Put _grain.png into patterns if present.
  4. Restart Krita, or use Settings → Manage Resources → Import Resources to add them without restarting.
  5. Open the preset (F6) and check the brush tip (F5 → Brush Tip → Predefined). Re-pick the imported PNG there if Krita doesn't auto-link it, and adjust size/spacing/opacity to taste.

The .kpp this generates is a best-effort starting point — it carries over the real brush artwork, but Procreate's shape dynamics, jitter curves and blend settings don't map 1:1 to Krita's engine, so some hand-tuning of the preset is expected. The shape/grain PNGs themselves are always extracted exactly as Procreate stored them.
